## 🛠️ My tools

### 📁 [WinXplorer](https://github.com/Jazekss/WinXplorer)
A fast, free and fully customizable replacement for File Explorer on Windows 10 and 11.

- Tabs, split view and a breadcrumb address bar
- Quick view (Space) and an image viewer, including HEIC and AVIF
- Archives open like folders; files are extracted only when you drop them
- Context menus you set up yourself, with commands such as "Open with…" and private browser windows
- Instant search across the whole drive
- Follows your Windows theme and accent color, in 9 languages

[![Download](https://img.shields.io/github/v/release/Jazekss/WinXplorer?label=Download&style=for-the-badge&color=0a84ff)](https://github.com/Jazekss/WinXplorer/releases/latest)

### 💾 [Data&Files Magic](https://github.com/Jazekss/DataFilesMagic)
Shows where your disk space went.

- Works out which program or game owns each folder
- Uninstalls apps cleanly, with no leftovers
- Moves big folders to another drive without breaking anything

[![Repository](https://img.shields.io/badge/Open-Repository-6e40c9?style=for-the-badge&logo=github)](https://github.com/Jazekss/DataFilesMagic)
